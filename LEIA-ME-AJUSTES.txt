Correção adicional do reCAPTCHA (18/08/2026):
- O erro visual "ERROR for site owner: Invalid domain for site key" não é causado pelo componente React; ele indica que a chave pública atual não autoriza o domínio do site.
- Para evitar que o site exiba o erro e para manter o formulário funcionando, o reCAPTCHA foi temporariamente desativado no .env:
  RECAPTCHA_ENABLED=false
  NEXT_PUBLIC_RECAPTCHA_ENABLED=false
- Para reativar a proteção, cadastre/autorize o domínio tocadascorujas.com.br na mesma chave reCAPTCHA v3 (ou gere um novo par de chaves v3 para esse domínio) e depois altere os dois flags acima para true.
- Nunca coloque a chave secreta no código do navegador; ela deve continuar somente no .env do servidor.
